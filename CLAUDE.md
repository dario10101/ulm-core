# ULM Core

Backend de ULM (gestion personal: habitos, finanzas, contenido). API REST consumida por `ulm-web`.

**Stack**: Python 3.12, FastAPI, Uvicorn, Pydantic v2, PostgreSQL (pendiente integrar), Pytest.

**Estructura**: `app/api/routes` (endpoints), `app/core` (config), `app/models` (Pydantic), `tests/`.

Estilo: ver STYLEGUIDE.md (codigo en ingles, comentarios/logs en espanol).
